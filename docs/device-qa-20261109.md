## Fixes from the review

- Header and share controls have at least 44 × 44 CSS-pixel targets; header controls have comfortable spacing.
- Detail/clear/back-to-top actions and footer links have at least 44-pixel target height.
- Short landscape screens show the hero headline within the initial viewport.
- Small project-detail links use the existing foreground token for sufficient contrast in both themes; large price text retains the existing AKTAL accent.
- Navigation labels for assistive technology follow the chosen language.
- Mobile filter-submit text remains visible after arrow removal.

## Functional journeys

Completed on 390 × 844, 768 × 1024 and 1440 × 900:

- Jeddah filter returns its two project snapshots only.
- Off-plan + Jeddah produces the empty state; reset restores all 14 projects.
- Arabic project-name search returns the matching project.
- Switching to English while scrolled retains the search and keeps the header available.
- Price ascending puts View Arch Residence first.
- Project dialog fits the viewport without horizontal overflow.
- Closing and browser Back retain filters/sorting and return to the list.
- Side drawer opens, closes and navigates Home / Projects / Broker Platform.
- Light/dark switching preserves functionality.

Also verified: share-link copy succeeds; Escape closes language and side menus; background scrolling unlocks after drawer close; no browser console errors during the journeys. Emulated reduced-motion preference disables the sheen and transitions and was reset afterward.
