# AKTAL Independent Design Preview

Independent static front-end. No Lovable project changes, CRM integration, customer data or production writes.

Reference reviewed 9 November 2026: https://www.jewarsa.com/ar/categories and homepage.
- Full-bleed architectural hero, centered lower headline and subtitle.
- Overlay navigation, full-width editorial rhythm and search/filter tray.
- Preserve AKTAL project cards, three columns on desktop, two tablet, one phone.
- Header: Home / Projects / Brokers. Remaining links in accessible side drawer.

Brand constraint: keep existing AKTAL website colors and typeface unchanged.
- Midnight #0D0A24, Aktal #1F1A4D, Lotus #7B71C2, white #FFFFFF, cream #E4DFDB.
- IBM Plex Sans Arabic (current production computed font); no typography replacement.
- Official AKTAL white horizontal logo.
- Use only existing AKTAL public project photography/content. Snapshot, not live availability.

Interactions: project search and city/district/delivery filters, clear filters, project detail preview, language Arabic/English, system/light/dark appearance, keyboard accessible drawer and dialogs, reduced-motion support.

Deploy target: separate GitHub repository + GitHub Pages. Relative paths; no build dependencies.
